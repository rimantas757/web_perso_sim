Personalise · install

A tiny website personalization engine that runs from your bookmarks bar. Tag any page while you browse, and configure rules that swap heroes, show popups, or run scripts when a topic score crosses a threshold.

1Grab the bookmarklet

Drag this button to your bookmarks bar:

⚡ Personalise Preparing…

Then click the bookmark on any website. The Personalise panel appears bottom-right.

2If step 1 doesn't work — use the inline version

Some sites use a strict Content Security Policy (CSP) that blocks loading external scripts, including the loader bookmarklet. This alternative bundles the entire engine into a single bookmarklet so nothing needs to be fetched from the web.

⚡ Personalise (inline) Preparing…

Same look and feel, but the whole engine lives inside the bookmark URL — heavier but bulletproof.

3Absolute last resort — DevTools snippet

If both bookmarklets fail (very rare — some intranet sites strip javascript: URLs), paste the engine into browser DevTools:

  1. Open the target website
  2. Press F12 (or right-click → Inspect)
  3. Go to the Console tab
  4. Paste and press Enter

Note: some sites disable the console via Object.defineProperty tricks. If pasting shows "Sorry, this site disabled console paste", type allow pasting then Enter first.

What you can do once it's loaded

  • Runtime mode — see tag scores accumulating as you browse, watch threshold rules fire.
  • Config mode — manage topics, click "Add rule" on each page to tag it with a topic + weight, then wire threshold rules that swap images, show popups, or run custom scripts.
  • Click-to-pick — instead of typing a CSS selector, click the "Pick" button and click any element on the page to capture its selector.
  • Export/Import — save your entire config as JSON to share or move between environments.
  • Zero-flicker — image-swap rules that have already fired are pre-applied via CSS injection before the browser paints, so users never see the original.
