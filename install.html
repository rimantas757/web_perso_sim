Personalise · install

A tiny website personalization engine that auto-loads on every page of a chosen site. Tag pages while you browse, then wire rules that swap heroes, tweak buttons, show popups, or run custom scripts when a topic score crosses a threshold.

1Install Tampermonkey

Tampermonkey is a free browser extension that runs userscripts on the sites you tell it to. If you already have it, skip to step 2.

Didn't see the Tampermonkey install dialog?

Sometimes the browser just downloads the file or opens it as plain text. Use this fallback:

  1. Click Copy scoped code below.
  2. Click the Tampermonkey icon in your browser toolbar → Create a new script….
  3. Select all the placeholder code in the new tab and paste (Ctrl/Cmd + V).
  4. Save (Ctrl/Cmd + S). Done.

3Use it

  1. Go to the site you scoped the script to. A blue Salesforce cloud badge appears in the bottom-right.
  2. Click + on the badge to expand the panel. Switch to the Config tab.
  3. Rename Topics to the segments you care about (e.g. Sri Lanka interest, Family holidays).
  4. Browse to a page and click Add rule — that URL now contributes to the topic you chose.
  5. Click + Add threshold rule for this page to wire what happens when the score hits your threshold. Pick Swap image, Popup, or Run script. Use Pick to click any element on the page and capture its CSS selector.
  6. Use ⬇ Export / ⬆ Import in the Config tab to save your setup as a JSON file (web_perso_story__<hostname>__<date>.json) and share it or restore later.
  7. Switch back to Runtime to see live scores. Reloads and navigations persist — the userscript re-runs on every page.
