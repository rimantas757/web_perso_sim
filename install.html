Personalise · install

A tiny website personalization engine that auto-loads on every page you visit. Tag pages while you browse, then wire rules that swap heroes, tweak buttons, show popups, or run custom scripts when a topic score crosses a threshold.

1Install Tampermonkey

Tampermonkey is a free browser extension that runs userscripts on every page. If you already have it, skip to step 2.

Get Tampermonkey → (Chrome, Edge, Firefox, Safari, Opera).

2Install the Personalise userscript

Click the button below. Tampermonkey will open its install dialog — click Install in there and you're done.

⚡ Install Personalise Loading…

By default the script runs on *://*/* — every website you visit. To scope it to one site, open the Tampermonkey dashboard, click the Personalise script, and change the @match line (e.g. *://*.audleytravel.com/*).

3Use it

  1. Go to any website. A green Personalise panel appears in the bottom-right.
  2. Switch to the Config tab.
  3. Rename Topics to whatever segments you care about (e.g. Sri Lanka interest, Family holidays).
  4. Browse to a page and click Add rule — that URL now contributes to the topic you chose.
  5. Click + Add threshold rule for this page to wire what happens when the score hits your threshold. Pick Swap image, Popup, or Run script for full control. Use Pick to click any element on the page and capture its CSS selector.
  6. Switch back to Runtime to see live scores. Reloads and navigations are persistent — the userscript re-runs on every page.

How updates work

Tampermonkey checks @updateURL daily and quietly pulls new versions. To force an immediate refresh, open the Tampermonkey dashboard → click the utilities tab → Check for userscript updates.
